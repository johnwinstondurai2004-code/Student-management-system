# Student Management System (MERN, 3D UI)

## Run
1. Start MongoDB (local) or use Atlas.
2. Backend:
   cd server && cp .env.example .env && npm install && npm run dev   (http://localhost:5000)
3. Frontend:
   cd client && npm install && npm run dev                          (http://localhost:5173)

## Features
- Add / edit / delete / search students
- 3D tilt cards, floating 3D cube hero, glass UI, dark theme
- Photo upload ONLY after a permission prompt; consent is stored and enforced by the server
